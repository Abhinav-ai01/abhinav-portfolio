# Abhinav Portfolio Website

A responsive, single-page portfolio for AI/ML, Python, LLM application, data, and software engineering opportunities.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.
3. For a local server, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Deploy free with GitHub Pages
1. Create a GitHub repository named `Abhinav-ai01.github.io` (or another repository for the portfolio).
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the website.

## Before publishing
- Check phone number and email are the contact details you want public.
- Verify project descriptions against the latest code in each repository.
- Add a downloadable resume PDF if you want recruiters to download it.
- Consider replacing the placeholder “open to opportunities” text if your preferences change.

## Notes
- No backend or API key is required.
- Google Fonts are loaded from Google Fonts; the rest of the site is static.
- Project links point to the public GitHub repositories.
